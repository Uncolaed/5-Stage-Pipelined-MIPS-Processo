# Test Cases and Reference Modules

This folder contains older standalone/reference VHDL modules that were used while building the CPU.

These files are useful for studying individual stages and the earlier single-cycle reference design, but they are not part of the main pipelined CPU build. Some entity names intentionally overlap with files under `src/`, so compile them in a separate ISE project if you want to experiment with them.

For the main pipelined CPU, use only the sources listed in `../docs/source_order.md`.
